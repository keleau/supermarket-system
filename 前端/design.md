# 超市商品管理系统 · 设计规范（design.md）

> 本文件是本项目**唯一的视觉与交互约束**，后续所有页面开发必须遵循。
> 所有设计令牌（颜色、字号、圆角、阴影、动效）均已在 `src/styles/index.css` 以 CSS 变量落地，业务代码**只能引用变量，禁止硬编码色值与阴影**。
> 技术栈：Vue 3（`<script setup>`，纯 JavaScript，无 TypeScript）+ Element Plus + vue-router + axios。

---

## 1. 设计定位

| 项 | 结论 |
| --- | --- |
| 产品类型 | B2B 超市商品库存管理后台（内部运营工具，非营销网站） |
| 使用角色 | 管理员（全权限）、仓管（日常出入库与库存查看） |
| 设计语言 | 克制冷静的商业级后台：**深墨青侧边栏 + 白色内容区 + 单一翡翠绿品牌色** |
| 品牌色立意 | 翡翠绿呼应超市"生鲜、可靠"，同时区别于满大街的蓝色后台模板 |
| 设计档位 | 规整度 3 / 动效强度 4 / 信息密度 6（规整优先，动效仅服务层级与反馈） |

### 五条核心原则

1. **功能优先**：信息层级清晰，操作路径短，不做装饰性大图形。
2. **单一强调色**：全项目只有翡翠绿一个品牌强调色，状态色只承担语义。
3. **真实质感**：阴影必须带冷色染色，禁止纯黑投影、霓虹发光、高饱和渐变。
4. **动效有动机**：每个动画只能用于反馈（点击/加载）、层级（弹层/抽屉）或空间关系（页面切换/折叠）。
5. **体系一致**：圆角、间距、字号、图标全部走令牌刻度，不允许页面自创风格。

## 3. 字体与排版

### 3.1 字体族

```
-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif
```

使用系统字体栈（零网络加载、中文渲染稳定），禁止引入花哨字体、禁止艺术字标题。

### 3.2 字号刻度

| 级别 | 大小 | 用途 |
| --- | --- | --- |
| 展示数字 | 26–28px / 700 | 统计卡片大数字（数字用等宽数字特性） |
| 页面标题 | 18px / 600 | 卡片标题、占位页标题 |
| 区块小标题 | 15–16px / 600 | 弹窗标题、表单分区 |
| 正文（基准） | 14px / 400–500 | 表格、表单、菜单 |
| 辅助文字 | 13px / 400 | 面包屑、次要信息 |
| 注释 | 12px / 400 | 角标、版权、弱提示 |

- 行高：正文 1.6–1.8，标题 1.3–1.4。
- 字重只允许 `400 / 500 / 600 / 700`。
- 表格中的数量、金额、价格等数字加 `class="num"`（`font-variant-numeric: tabular-nums`），保证纵向对齐。
- 金额单位"元"、数量单位等用 12px 次要色，不与数字同字号同色。

## 4. 间距、圆角与阴影

### 4.1 间距刻度（8px 栅格）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`，页面外边距固定 **20px**，卡片内边距 **20px**，卡片之间 **16px**，表单项纵向 **16–20px**。

### 4.2 圆角（形状一致性，三套刻度不可混用）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-control` | 8px | 按钮、输入框、下拉、菜单项 |
| `--radius-card` | 12px | 卡片、弹窗、登录卡片 |
| `--radius-pill` | 999px | 标签 Tag、头像、状态点、指示条 |

### 4.3 阴影（冷色染色，禁止纯黑）

| 令牌 | 用途 |
| --- | --- |
| `--shadow-xs` | 卡片静态描边感、顶栏 |
| `--shadow-sm` | 普通悬停、下拉 |
| `--shadow-md` | 弹窗、抽屉、主按钮投影 |
| `--shadow-lg` | 登录卡片、全局大弹窗 |

卡片默认 `1px var(--border-light)` 描边 + `--shadow-xs`，**不要**给表格容器加厚重阴影。

## 5. 布局规范

### 5.1 整体结构

```
┌────────┬──────────────────────────────┐
│ 深色   │  顶栏 60px（折叠钮 + 面包屑 + 用户）│
│ 侧边栏 ├──────────────────────────────┤
│ 232/64 │  内容区 padding:20px           │
│        │  （页面卡片 / 列表 / 表单）      │
└────────┴──────────────────────────────┘
```

- 侧边栏展开 `232px`、折叠 `64px`；顶栏高 `60px`；均为令牌，不要另写数值。
- 内容区底色 `--bg-page`，业务内容统一放入白色卡片（工具类 `page-card`）。
- 小屏（≤ 900px）：登录页隐藏品牌区；后续表格页需横向滚动而不是压缩列。

### 5.2 列表页标准骨架（后续业务页统一照此搭建）

1. **筛选卡片**：查询条件行（el-form inline）+ 右侧"查询 / 重置"，可扩展操作放左侧"新增"主按钮。
2. **表格卡片**：el-table 紧接其下，表头使用 `--bg-muted`；操作列固定右侧，文字按钮（编辑=主色、删除=danger）。
3. **分页**：表格卡片右下角，el-pagination（total + page-sizes + jumper）。
4. 弹窗（el-dialog）承载新增/编辑表单：标签在上或左、错误提示在输入框下方；确认按钮放右下角。

### 5.3 登录页

左品牌区（46%，深色 + 翡翠光晕 + 细网格 + 品牌数据速览，≤900px 隐藏）+ 右白色登录卡片（最大宽 448px、内边距 48/44/40，`--shadow-lg`，12px 圆角，右上角配倾斜收银小票装饰）。该版式为固定品牌资产，不随业务改动。

- **品牌数据速览**：两格宣传数据（5 大品类全覆盖 / 100% 变动可追溯），数字 26px/700 翡翠色等宽 + 12px 次要色标签，上下细线 + 竖分隔线；为宣传口径，非实时业务数据。
- **品牌区氛围**：墨青→深翠 152° 对角渐变底（2.5 令牌，禁止纯黑平涂），四角翡翠光晕（左上主光 + 右下地平线 + 左下补光 + 右上冷青光）+ 短程斜向光束，带 9s 慢速呼吸；22 颗翡翠/白色光点粒子上浮漂浮（约 2/3 偏置左下黑场，负延迟相位分布，随机生成一次）；功能条目为玻璃卡（rgba 白 3% 底 + 细描边，hover 上浮 2px + 翡翠描边）；logo 行右侧系统状态徽标（检测中/系统运行中/后端离线，在线点带低频 ping）。
- **收银小票装饰**：等宽字体、虚线分隔、conic-gradient 锯齿底边、合计用品牌色；纯装饰（aria-hidden），≤900px 隐藏，不承载真实数据。
- **标题强调字**：翡翠色文字 + 半透明"荧光笔"下划高亮（入场时 scaleX 从左向右扫入）。
- **表单区氛围**：浅点阵底纹 + 品牌/图表色静态氛围晕（非动画）；时间问候语按打开时刻静态计算（夜深了/早上好/中午好/下午好/晚上好），不做时钟轮询。
- **演示账号联动**：点选或填入演示账号后对应 chip 高亮（`--brand-primary-light-9` 浅底）。

## 6. 组件使用规范（Element Plus）

| 组件 | 规范 |
| --- | --- |
| Button | 一个操作区只有一个 `type="primary"`；次要用 default / text；危险操作（删除、出库红冲）才用 danger；禁止彩色满屏按钮。按下保持物理下沉感。 |
| Input / Select | 高度沿用 EP 默认（大表单可用 size="large"）；label 在输入框上方或左侧对齐；placeholder 只写示例不充当 label。 |
| Form | 前端只做轻量校验：**非空、数字必须 > 0**。库存是否充足、库存变动、流水生成等一律由 Node 后端校验，失败时直接展示后端 `msg`。 |
| Table | 表头浅灰、行高舒适（≈44px）、hover 行 `--bg-muted`；金额/数量右对齐 + 等宽数字；空数据用 EP 默认空态或统一插画位。 |
| Tag / 状态 | 状态用语义色浅底：正常 success、预警 warning、缺货/禁用 danger；同一状态全项目颜色一致。 |
| Dialog | 圆角 12px，标题 16px/600；底部按钮右对齐；打开/关闭使用 EP 自带过渡，不额外加弹跳。 |
| Message | 统一由 axios 响应拦截器弹出（后端 `msg`），业务代码不要重复弹同一条错误；成功提示才在业务代码中主动给出。 |
| Pagination | 文案中文，默认每页 10 条，可选 10/20/50。 |
| 图标 | 仅使用 `@element-plus/icons-vue`，默认尺寸随文字（16–17px），单色系，禁止手写 SVG 业务图标与 emoji。 |

## 7. 动效规范

### 7.1 动效令牌（已落地，禁止自写时长/曲线）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--motion-fast` | 0.18s | hover、颜色反馈 |
| `--motion-base` | 0.25s | 常规进出、弹层 |
| `--motion-slow` | 0.32s | 侧边栏折叠、页面切换 |
| `--ease-standard` | `cubic-bezier(.4,0,.2,1)` | 通用 |
| `--ease-decel` | `cubic-bezier(.16,1,.3,1)` | 元素入场 |
| `--ease-spring` | `cubic-bezier(.34,1.3,.64,1)` | 小元素回弹（折叠箭头） |

### 7.2 动效清单（项目允许的全部动画）

1. **侧边栏折叠/展开**：宽度 0.32s standard；Logo 文字淡入淡出；箭头 0.32s spring 旋转 180°。
2. **页面切换**：旧页面上浮 4px 淡出（0.18s）→ 新页面下沉 8px 淡入（0.32s decel），已通过 `page-fade` 过渡内置在 Layout。
3. **菜单**：背景色/文字色 0.18s 过渡；子菜单展开沿用 EP 过渡。
4. **按钮/可点击块**：hover 颜色过渡，`:active` 下沉 1px（工具类 `tactile`）。
5. **弹窗/下拉/气泡**：使用 EP 默认过渡，不加重力/回弹。
6. **登录入场**：品牌区条目按 90ms 级联上浮淡入，登录卡片上浮淡入（仅登录页首次加载）。
7. **登录页装饰入场**：数据速览与功能条目级联上浮淡入、收银小票从登录卡片内"打印滑出"（先藏于卡片后升出→过冲回摆→落定倾斜位）、标题荧光笔下划从左向右扫入（均为一次性，非循环）。
8. **登录页常驻循环例外**（7.3 无限循环禁令的唯一豁免，仅限登录页品牌区）：光晕 9s 呼吸（纯 opacity）、在线状态点 2.6s ping（transform+opacity）、粒子 8–16s 上浮漂浮（transform+opacity）；均低频、低对比，`prefers-reduced-motion` 下自动停用。

### 7.3 硬性禁令

- 只允许动画 `transform` 与 `opacity`，**禁止动画 width/height/top/left**（侧边栏宽度折叠为唯一例外，且必须使用令牌时长）。
- 禁止无限循环动画、漂浮光斑、跑马灯、数字滚动噪声（登录页/后台均不允许）。
- 禁止跟随鼠标的磁吸、视差、自定义光标。
- 禁止给每个卡片加 hover 上浮与发光；仅真实可点击卡片允许轻微反馈。
- 必须尊重系统 `prefers-reduced-motion`：降级策略为**循环动画默认收敛为单次播放、CSS 过渡即时化**，≤1.2s 的一次性入场动画保留正常播放；唯一豁免是登录页已登记的低频装饰循环（光晕 9s / 粒子 7–16s / 在线点 ping 2.6s）与 EP 加载旋转（在 `index.css` 全局落地，勿在页面覆盖或回退为"全部动画清零"的旧策略）。

## 8. 层级（z-index）刻度

只允许取：`--z-layout:100` → `--z-header:101` → `--z-dropdown:200` → `--z-modal:300` → `--z-toast:400`，禁止随手写 `z-index: 9999`。

---

## 9. 交互与校验分工（前端 / Node 后端边界）

- 前端：非空、数字 > 0 的轻量校验；加载中禁用按钮；失败只展示后端 `msg`。
- 后端：出库库存充足性判断、实际库存增减、出入库流水自动生成、删除约束（分类/供应商被引用时拦截）、用户角色鉴权（前端隐藏菜单不等于安全，后端必须二次鉴权）。
- 统一响应体：`{ code: number; msg: string; data: any }`，`code === 200` 成功，`401` 登录失效，其余非 200 直接弹 `msg`。

---

## 10. 禁用清单（出现即视为不合格）

1. 紫色/蓝色发光渐变、霓虹色、玻璃拟态滥用。
2. 纯黑 `#000` 背景、纯白刺眼大色块无层次、高饱和（>80%）强调色。
3. 暖灰与冷灰混用；同一页面出现多套圆角或多种阴影风格。
4. 硬编码色值 / 阴影 / 动画时长（不走 CSS 变量）。
5. emoji 充当图标、手写 SVG 图标、多套图标库混用。
6. 表单 placeholder 代替 label；错误提示用 alert；前端替后端做核心业务校验。
7. 页面出现与业务无关的装饰插画、3D 元素、自动播放动画。
8. 侧边栏折叠后文字挤压错位；页面切换无反馈或反馈超过 0.4s。
9. 弹窗出现两个以上主按钮；危险操作无二次确认。
10. 新增页面不使用 12px 卡片容器，内容直接贴在灰色背景上。
