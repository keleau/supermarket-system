B端后台超市管家全页面响应式布局优化，基于Element Plus 24栅格系统，适配浏览器窗口缩放，在不同窗口宽度下自动调整布局，保证内容完整、层级清晰、操作可用，无挤压重叠、无内容溢出。

### 一、整体页面框架响应式
1. 大屏（宽度 ≥ 1200px）：左侧侧边栏完整展开，显示图标+文字菜单；右侧主内容区正常排布，页面左右留白均匀。
2. 中屏（992px ≤ 宽度 ＜ 1200px）：侧边栏保持展开，主内容区内边距适当缩小，内容区域自适应占满剩余宽度。
3. 小屏（768px ≤ 宽度 ＜ 992px）：侧边栏自动折叠为仅显示图标的窄侧边栏；主内容区占满剩余宽度，页面内边距进一步收窄。
4. 超小屏（宽度 ＜ 768px）：侧边栏默认收起隐藏，点击菜单按钮滑出；主内容区占满全屏宽度。

### 二、顶部筛选栏响应式（核心优化）
1. 大屏：所有筛选输入框、下拉选择器横向排成一行，操作按钮固定在最右侧，整体水平对齐。
2. 中屏：筛选控件按「名称+条码」「分类+状态」自动分为两组，保持一行；操作按钮仍固定右侧，按钮间距适当缩小。
3. 小屏：筛选控件自动换行，分为两行；第一行放商品名称、条码输入框，第二行放分类、状态下拉框；操作按钮单独占一行，整体右对齐，「新增商品」「查询」保持主按钮视觉权重。
4. 所有输入框、按钮高度保持统一，换行后上下间距一致，无错位、无挤压。

### 三、统计卡片区域响应式
1. 大屏：一行均匀排列4张统计卡片，卡片宽度等分。
2. 中屏：自动调整为一行3张，剩余卡片换行到下一行，左对齐排列。
3. 小屏：自动调整为一行2张，卡片等宽，上下行间距统一。
4. 超小屏：一行1张，卡片占满内容区宽度，纵向堆叠。
5. 卡片内边距随宽度自适应缩小，数值、文字字号对应微调，保证信息完整展示不换行。

### 四、数据表格区域响应式（商品档案/销售记录通用）
1. 中屏及以上：完整展示所有列，列宽按内容权重自适应分配。
2. 小屏：
   - 表格外层开启横向滚动，表格整体宽度保持内容最小宽度，可左右滑动查看完整列；
   - 自动隐藏次要列（如供应商、规格、条码），仅保留核心列（商品名称/单据编号、金额、库存/状态、操作）；
   - 操作列的按钮保持完整，不折叠、不挤压。
3. 分页组件：宽度缩小时，页码按钮自动减少显示数量，保留首页、末页、当前页和前后页，跳转框保持可用。

### 五、通用适配细节
1. 所有卡片、输入框、按钮的圆角、边框样式保持统一，仅尺寸随布局等比缩放。
2. 文字层级保持不变，主标题、正文、辅助文字字号按断点阶梯式缩小，不出现文字重叠。
3. 页面内所有间距（外边距、内边距）按断点成比例调整，避免大留白或过度拥挤。
4. 所有弹窗组件宽度随窗口自适应，最大宽度不超过窗口宽度90%，高度超出时内容区域开启滚动，底部操作按钮固定。
