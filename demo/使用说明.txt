超市管家演示包 · 使用说明
==============================

说明：下文中的 app\backend\.env 等路径，都是相对于解压后的演示包根目录
（即 start-demo.bat 所在目录）；不是项目源码根目录。

一、首次使用
1. 解压到任意目录（路径尽量不要含特殊符号）。
2. 确认学校电脑的 MySQL 服务已启动，端口默认 3306。
3. 双击 start-demo.bat。
4. 首次运行会把 app\backend\.env.demo 复制为 app\backend\.env 并打开：
   - 默认 DB_USER=root，DB_PASSWORD=123456
   - 如果学校 MySQL 密码不同，请修改后保存并关闭记事本。
   - 也可以提前编辑 app\backend\.env.demo，首次启动会自动复制。
5. 启动器会自动创建演示库 supermarket_demo、建 14 张表、写入演示账号和商品数据。
6. 浏览器会自动打开 http://localhost:3000。

三、常用操作
停止服务：双击 stop-demo.bat（不要直接结束启动窗口）
修改数据库配置：双击 配置数据库.bat
重置演示数据：先停止服务，再双击 reset-demo.bat
（reset 会清空演示库数据并重新写入种子数据，不要对正式库使用）

四、常见问题
1. 提示无法连接 MySQL：
   - 打开 Windows「服务」，启动 MySQL 服务；
   - 检查 app\backend\.env 的 DB_HOST / DB_PORT / DB_USER / DB_PASSWORD；
   - 确认 MySQL 端口默认 3306，或按实际端口修改。
2. 3000 端口被占用：
   - 启动器会自动尝试 3001~3019，并以控制台打印的地址为准。
3. 页面能打开但接口报错：
   - 查看启动窗口中的错误信息；
   - 确认 MySQL 服务仍在运行。
4. 浏览器显示旧页面：
   - 使用无痕窗口，或清理浏览器该站点数据后重试。
5. 现场没有网络：
   - 本演示包不依赖外网；用户头像外链会退化为姓名首字，不影响功能。

五、演示建议
- 答辩当天早上执行一次 reset-demo.bat，让「近 7 天趋势」等种子数据保持新鲜。
- 主流程先用 admin 走完，再切换收银员/仓管/会计展示权限差异。
- 登录接口同一 IP 每分钟最多 5 次尝试；如触发限制，等待 1 分钟或重启服务。
