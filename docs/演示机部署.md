# 演示机部署与学习通交付

目标：在学校电脑上只做两件事——**启动 MySQL、解压后双击 `start-demo.bat`**。Node 运行时、前端构建产物、后端依赖都放在演示包里。

## 一、打包（在自己的 Windows x64 电脑上执行）

前置条件：

- `backend/node_modules` 已安装（`cd backend && npm ci`）
- 演示机已安装 MySQL 8.x，并能用某个账号连接
- 打包机是 Windows x64（演示包会复制当前电脑的 `node.exe`）

执行：

```bash
# 在项目根目录
node scripts/package-demo.js
```

生成：

```text
release/
├── 超市管家-演示包/
└── 超市管家-演示包.zip
```

把 zip 上传到学习通即可。包内不包含 MySQL，也不包含任何真实数据库密码。

如果不想立刻压缩，可以先只生成目录做本地验证：

```bash
node scripts/package-demo.js --no-zip
```

## 二、演示包结构

```text
超市管家-演示包/
├── start-demo.bat          # 双击启动
├── stop-demo.bat           # 停止服务
├── reset-demo.bat          # 重建演示数据（会清空演示库）
├── 配置数据库.bat           # 打开 .env 编辑 MySQL 连接
├── 使用说明.txt
├── runtime/
│   └── node.exe            # 便携 Node，无需安装
└── app/
    ├── backend/
    │   ├── app.js
    │   ├── node_modules/
    │   ├── .env.demo       # 首次启动复制为 .env
    │   └── scripts/demoLauncher.js
    └── frontend/
        └── dist/           # Vue 构建产物
```

## 三、学校电脑上的操作

1. 确认 MySQL 服务已启动（Windows 服务管理器 → MySQL → 启动）。
2. 解压 `超市管家-演示包.zip` 到任意目录。
3. 双击 `start-demo.bat`。
4. 首次运行会打开 `app\backend\.env`：
   - 默认 `DB_USER=root`、`DB_PASSWORD=123456`
   - 按学校电脑实际情况修改，保存并关闭记事本。
5. 启动器会：
   - 检查 MySQL；
   - 首次运行时自动创建 `supermarket_demo` 库、14 张表和演示数据；
   - 启动后端并托管前端；
   - 自动打开 `http://localhost:3000`（3000 被占用时自动换端口）。
6. 演示结束双击 `stop-demo.bat`。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| 提示无法连接 MySQL | 启动 MySQL 服务；检查 `.env` 的 `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD` |
| 提示账号密码错误 | 双击 `配置数据库.bat` 修改账号密码，保存后重新启动 |
| 3000 端口被占用 | 启动器自动尝试 3001~3019，以控制台打印地址为准 |
| 页面能打开但接口报错 | 查看启动窗口错误；确认 MySQL 仍在运行 |
| 浏览器显示旧页面 | 使用无痕窗口，或清理该站点 localStorage |
| 登录提示尝试过于频繁 | 同一 IP 每分钟最多 5 次登录，等待 1 分钟或重启服务 |
| 演示机禁止运行 U 盘/下载的 exe | 方案不可用，改用自带笔记本或云端地址演示 |

## 六、安全说明

- `.env` 含数据库密码和 JWT 密钥，演示包中只放 `.env.demo` 模板，首次运行才生成 `.env`。
- 演示库固定使用 `supermarket_demo`，不要指向学校其他业务库。
- `reset-demo.bat` 会重建表并清空演示库数据，只在演示库使用。
